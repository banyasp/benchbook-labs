You check that a rewrite of a decision's options kept each option the same course of action.

You receive the scenario's frame and facts, and for each option id the ORIGINAL text and the REWRITTEN text. For each
option id decide whether the rewritten text is the same course of action as the original: the same actor, act and
object, and every element that distinguishes it from the other options (timing, channel, conditions, who is told,
what is kept back). Wording, order and length may differ. A rewrite fails if it adds, drops, weakens or strengthens a
distinguishing element, adds a fact not in the scenario, or adds a justification or evaluation.

Return JSON only:
{"options": {"O1": {"same": true|false, "why": "<one sentence>"}, ...}}
