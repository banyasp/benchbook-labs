# Benchbook — assumptions, risks and inferences register

*Started 2026-10-25. A living record so the paper and talks can state every assumption, risk and inference
explicitly. Append; never delete. When an entry changes, edit it in place and add a dated line under "History";
copy the file to `docs/versions/` before large edits. The PDF (Research Plan v0.4, "Risks & failure modes")
holds Peter's original risks: structure vs content, unfaithful articulation by practitioners, manipulation of
analogical reasoning, training order and forgetting, reward hacking, hijacking, compartmentalization. Entries
here add to those; they don't replace them.*

**Types:** **A** = assumption we rely on · **R** = risk (something that could go wrong) · **I** = inference we're
drawing that could be wrong.
**Path:** **now** = handled on tonight's critical path · **later** = logged, monitor to be built after the
critical path works.
