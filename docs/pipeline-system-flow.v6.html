System flow

gpt-oss-120b on Bedrock Granite 4.2 8B, local vLLM Jev judge (OpenRouter) Code only Stored artifact Peter T2 / v2, or not default solid arrow: data flow · dotted: side input, alternative or later

G, the gold record, is assembled by code only from what extract, perturb and pair recorded. No model writes any part of it. A model writes only the SFT text Y, and Y is kept only when its structure matches G.

Notation

RThe raw corpus (Peter, 28 Oct): the fetched text and the cleaned, span-tagged paragraphs (data/docs). Downstream, R means data/docs, never model-rewritten.
Episode storeCandidate decision points found in R (8,617 from the natsec corpus), with rejects; a batch is selected from it by stratified quotas, per incident family.
X = (F, Q, A)A scenario, role-agnostic. F atomic facts · Q question frame (question, decider, agent role and authority, options) · A answer.
A = (K, W, V, Φ, lesson, limits)Considerations · reasoning · verdict · flip conditions · take-away principle and its boundaries.
C · TRoles, not kinds: a scenario served as a case (card) or rendered as a trace. Any scenario can play either.
E · E_dThe equity registry (ids and glosses); one deployment's injected subset.
skeleton[backend] Structural summary of X: question type, tension, decisive, conditions, move and authority shape.
F′ · Q′ · A′ · X′The perturbed facts or frame, the new answer, and the new scenario X′ = (F′, Q′, A′). Perturb changes only F or Q; A′ comes by construction or from an independent solve that never sees C.
C′ · Δ_KA revised card: the same F and Q with an edited answer A′; Δ_K lists the considerations whose weight or favors changed.
F_T · Q_T · K_T · V_TThe trace scenario's facts, frame, considerations and verdict, as gold.
ΔPerturb's exact record of what it changed. For a derived pair, Δ is the gold mapping.
M^F · M^KFact and consideration mappings between C and T: buckets (matched, corresponding, live_only, case_only) plus counterparts.
τ · σ · αThe rendered trace; its span map (facts and options); its allowed list (true details not in F_T).
GThe gold record for a pair, assembled by code only: F_T (decisive ×2), α, Q_T, M^F, K_T, M^K, governs, relation, via, V_T, gold tier, d.
PThe harness prompt: τ + E_d + card(C) for the arm (full or thin) ± the analogical-reasoning prompt.
YAn SFT target: the policy's full reply in the PDF step format.
d(C, T)Structural distance, structured YAML to structured YAML, never from traces.

Labels: [backend] never shown to a policy model · [served] in the prompt · [trained] in an SFT target or the RLVR gold. Tiers: built T1 before the 150+ pair batch · T2 after the first training run · v2 later.
