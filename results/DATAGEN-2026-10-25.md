## Rules followed / deviations

- **Gold verdicts** only from construction (restyle, flip), the source's endorsed answer (extract, decoys), or an
  independent solve that never sees C (add_fact; isolation is asserted in a test). The teacher never sets gold.
- **Teacher** = config role `teacher` (`config/models.yaml`: placeholder `bedrock/openai.gpt-oss-120b-1:0`,
  reasoning effort high, N = 3); given the full gold structure + touched condition + structure-mapping rubric.
  Never the base model.
- **Allowlist lifted to record-only** (`code/datagen/models.yaml: allowlist_mode: record`); every call records
  `allowlist: allowlisted | outside-allowlist:…` and its credential source. Provenance on every scenario/pair/sample
  (`Provenance.steps`, `fields`, `authored`).
- **Source substitution:** DOHA → DOE OHA (blocked, R28). Doctrine source = 5 CFR 2635 subpart B examples (eCFR
  API), each an official vignette with OGE's endorsed answer.
- **Deferred list not built** (grounding judge, render gates, salience probe, verbatim check, specificity gate,
  two-solver agreement, thin cards, twin contrast, Horty checker, legal corpus, natural pairs/index, transfer,
  review UI, judge validation, oracle audit). Render diagnostics (coverage, leaks, length) are logged only.
- Not done tonight: rendering/solving the 20 eval-only pilot decoys; exporting more than one accepted sample per
  pair; the `C`/`C′` SFT projections (code supports them; v0 is mode B).
